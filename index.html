Documentation

1 Getting Access Keys

  • Discord Bot Token: Visit the Developer Portal. Create App → Bot → Reset Token.
  • ⚠ Enable "Message Content Intent" in the Bot section!
  • Groq API Key: Visit Groq Cloud and generate a free key. This powers Llama 3.

2 Hosting — Easy (fps.ms)

  • Go to fps.ms, create a Python server
  • Upload the ZIP to the Files tab
  • Right-click → Unarchive
  • Click Start in Console

3 Hosting — Best (Koyeb)

  • Push files to a GitHub repo
  • Connect Koyeb to your GitHub
  • Select Buildpack builder
  • Deploy and you're live 24/7

4 Troubleshooting

  • Improper Token: Wrong Discord token — reset in Dev Portal.
  • 404 Model Error: Model name changed. Uses Llama 3.1.
  • Bot Not Replying: Check Message Content Intent is enabled.
