Documentation

1 Getting Access Keys

To make the bot work, you need two free keys:

  • Discord Bot Token: Go to the Discord Developer Portal. Create a new Application > Click 'Bot' > Click 'Reset Token'.
    IMPORTANT: Scroll down and enable "Message Content Intent" switch!
  • Groq API Key: Go to Groq Cloud. Create a free account and generate a new API Key. This powers the Llama 3 brain.

2 Hosting Guide

Once you click FINISH on the Home tab, you will download a ZIP file. You need to host this file to keep the bot online.

Option A: FPS.ms (Easiest)

1. Go to fps.ms and create a Python server.

2. Upload the ZIP file to the "Files" tab.

3. Right-click and "Unarchive" (Unzip).

4. Click Start in Console.

Option B: Koyeb (Best)

1. Create a GitHub repo and upload the files.

2. Connect Koyeb to your GitHub.

3. Use "Dockerfile" or "Buildpack" builder.

4. Deploy.

3 Troubleshooting

  • Improper Token: You pasted the wrong Discord Token. Reset it in the dev portal.
  • 404 Model Error: The AI model name changed. This generator uses the latest Llama 3.1.
  • Bot Not Replying: Did you enable "Message Content Intent" in Discord Dev Portal?
